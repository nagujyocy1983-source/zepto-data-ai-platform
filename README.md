# Zepto Data & AI Platform

An end-to-end Data, Analytics, and GenAI Support Assistant platform developed as part of the AI/ML Engineer Capstone Project.

## Project Overview

This project consists of three integrated modules representing an end-to-end AI/ML engineering workflow:

1. **Data Pipeline** - Web scraping, data cleaning, transformation, and SQLite database storage.
2. **Analytics Pipeline** - Exploratory data analysis, machine learning modeling, evaluation, and model persistence using the Titanic dataset.
3. **Support Assistant** - A grounded GenAI support assistant using document embeddings, ChromaDB, LangGraph, structured output, FastAPI, and Docker.
